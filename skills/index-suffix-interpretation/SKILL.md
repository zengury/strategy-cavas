# Index Suffix Interpretation

Interpret suffix characters attached to page numbers in book indexes to identify the type of referenced content.

## When to Use

- Reading an index entry with a page number followed by a single letter
- Need to determine whether a reference points to a footnote, table, figure, or boxed content
- Cross-referencing index entries with actual content in the book

## Suffix Reference Key

| Suffix | Meaning | Description |
|--------|---------|-------------|
| `n` | footnote | Reference appears in a footnote on that page |
| `t` | table | Reference appears in a table on that page |
| `f` | figure | Reference appears in a figure on that page |
| `h` | box | Reference appears in a boxed element on that page |

## Procedure

1. **Locate the page number** in the index entry
2. **Identify any trailing character** immediately following the number
3. **Match the suffix** against the reference key above
4. **Interpret the result** to understand what content type to locate on that page

## Examples

- `42n` → Page 42, in a footnote
- `15t` → Page 15, in a table
- `30f` → Page 30, in a figure
- `8h` → Page 8, in a box

## Notes

- Suffixes are always single lowercase letters
- No suffix indicates standard text reference on that page
- Multiple page numbers may appear for one index entry, each with independent suffixes
