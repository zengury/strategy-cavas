# Decision Bias Detection

Systematically identify cognitive biases that distort strategic judgment and forecasting accuracy.

## When to Use

- Before finalizing major strategic commitments
- During forecasting and budgeting cycles
- When post-hoc results differ dramatically from predictions
- When team consensus forms suspiciously quickly
- After successes or failures requiring honest assessment

## The Twelve Biases: Detection and Response

### 1. Confirmatory Search
**Signal**: Only seeking data that supports preferred conclusion
**Test**: "What evidence would prove us wrong? Are we actively seeking it?"
**Response**: Assign devil's advocate; require disconfirming evidence presentation

### 2. Inconsistency
**Signal**: Same criteria applied differently across similar situations
**Test**: "Would we decide the same way if [X factor] were different?"
**Response**: Document decision criteria in advance; audit past decisions for pattern

### 3. Conservatism (Slow Updating)
**Signal**: New information ignored; forecasts unchanged despite events
**Test**: "What would make us revise our view? Has that happened?"
**Response**: Force explicit Bayesian updating; pre-commit to revision triggers

### 4. Recency Bias
**Signal**: Latest events dominate; historical patterns forgotten
**Test**: "What happened in comparable periods 3-5 years ago?"
**Response**: Extend analysis window; weight historical base rates

### 5. Availability Bias
**Signal**: Vivid, memorable examples drive judgment; dull data ignored
**Test**: "Are we using this example because it's representative or memorable?"
**Response**: Systematic data search; check for silent evidence (failures not remembered)

### 6. Anchoring
**Signal**: Initial number becomes reference point; adjustments insufficient
**Test**: "What if the first number we heard was 10x higher/lower?"
**Response**: Generate independent estimates before exposure to anchors; use multiple starting points

### 7. Illusory Correlation
**Signal**: Pattern perceived in randomness; causality assumed without mechanism
**Test**: "What's the causal mechanism? Can we test with holdout data?"
**Response**: Require theoretical rationale; statistical validation; prediction markets

### 8. Selective Perception
**Signal**: Problems framed through functional background (marketing sees brand, ops sees logistics)
**Test**: "How would [different function] describe this problem?"
**Response**: Cross-functional review; external perspective inclusion

### 9. Regression Neglect
**Signal**: Expecting extreme performance to persist; ignoring mean reversion
**Test**: "What random factors might have caused this outcome?"
**Response**: Explicitly forecast regression; separate skill from luck

### 10. Self-Serving Attribution
**Signal**: Success = our skill; failure = bad luck/external factors
**Test**: "What did we do wrong in successes? What did we do right in failures?"
**Response**: Pre-commit to attribution rules; external audit of decisions

### 11. Optimism / Wishful Thinking
**Signal**: Forecasts consistently exceed outcomes; risk downplayed
**Test**: "Have we ever achieved timelines this aggressive?"
**Response**: Reference class forecasting; pre-mortems; outside view

### 12. Underestimating Uncertainty
**Signal**: Narrow confidence intervals; single-point forecasts; surprise when wrong
**Test**: "What's the 90% confidence interval? When were we last surprised?"
**Response**: Mandate range forecasts; track calibration; reward accurate uncertainty expression

## Rapid Bias Audit Protocol

For time-pressured decisions, run this 5-minute check:

```
1. OPTIMISM CHECK: What's the base rate of success for similar decisions?
2. ANCHOR CHECK: What if our primary number is off by 50%?
3. CONFIRMATION CHECK: Who disagrees and what do they know?
4. ATTENTION CHECK: What aren't we discussing that we should be?
5. UNCERTAINTY CHECK: What would surprise us? How would we know it's happening?
```

## When Bias Detection Fails

- **Groupthink**: Teams suppress dissent; use anonymous input first
- **Expert overconfidence**: Track expert prediction accuracy; weight accordingly
- **Sunk cost pressure**: Separate decision accountability from initial commitment
- **Time pressure**: Bias thrives under urgency; insist on minimum deliberation
