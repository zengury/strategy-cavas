# Strategic Frameworks Inventory

Quick reference for locating and applying strategic analysis frameworks from the source text.

## When to Use

- User asks "what strategic frameworks are covered?"

- Selecting appropriate tools for strategic analysis
- Comparing or contrasting multiple frameworks

**Industry/External Analysis**
- Five Forces (100-102)
- Competitive Analysis Model (100-102)
- Game Theory (108, 111b)

**Internal/Resource Analysis**
- BCG Matrix (94-99)
- Core Competency (217-219)
- Experience Curve (97)

**Positioning/Strategy Selection**
- Generic Strategies (83, 103-104)

## Usage Pattern

1. Identify user's analytical goal (external, internal, or positioning)
2. Reference appropriate framework(s) by page
3. Note: Five Forces and Competitive Analysis Model share pages (100-102) — they are closely related tools
