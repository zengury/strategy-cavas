# Core Competency Case Studies

## Honda: Engine Technology

**Market Access**: Enabled motorcycles, cars, lawn equipment, generators, marine engines
**Customer Benefit**: Reliability, power, fuel efficiency across all products
**Imitability Barrier**: Deep organizational knowledge in combustion, materials, precision manufacturing

Result: Competency persisted decades, supported massive diversification.

## Canon: Optical and Imaging

Applied precision mechanics, fine optics, microelectronics across:
- Cameras
- Copiers
- Semiconductor equipment
- Medical imaging

The coordination of these technologies, not any single one, created the competency.

## Failed Competency Claims

**DEC (Digital Equipment)**: Claimed "understanding of computing" but this was too broad, not specific coordination pattern. Failed when architecture shifted to PCs.

**Kmart**: Had scale and locations but lacked collective learning in logistics that Walmart developed. Resources without competency structure.

## Distinguishing Resources from Competencies

| Resources | Core Competencies |
|-----------|-------------------|
| What we have | What we know how to do |
| Can be acquired | Must be built |
| Individual elements | Patterns of coordination |
| Balance sheet items | Organizational capabilities |
| Depreciate | Can appreciate with use |
