# Strategic Resource Evaluation

Determine whether organizational resources and capabilities can deliver sustained competitive advantage through systematic criteria testing.

## When to Use

- Assessing if a resource justifies continued investment
- Evaluating capabilities before diversification decisions
- Prioritizing which strengths to protect and develop
- Analyzing competitive defensibility of internal assets

## VRIS Framework for Resources

Apply all four criteria. A resource must satisfy ALL to qualify as strategically valuable.

### 1. Value Test
Determine: Does this resource improve efficiency or effectiveness?
- Reduces costs or increases revenue?
- Enables opportunities or neutralizes threats?
- **Fail**: Resource is a competitive disadvantage

### 2. Rarity Test
Determine: Is the resource scarce relative to demand?
- Do few competitors possess it?
- Is it in high demand in the market?
- Examples: Prime real estate locations, unique talent, proprietary technology

### 3. Inimitability Test
Determine: Can competitors acquire or duplicate this resource?

| Source of Inimitability | Assessment Questions |
|------------------------|----------------------|
| Historical conditions | Does path dependency create advantage? (e.g., first-mover location) |
| Causal ambiguity | Is success source unclear even to insiders? |
| Social complexity | Does it depend on interpersonal relationships, culture, trust? |

### 4. Substitutability Test
Determine: Can competitors achieve the same outcome differently?
- Are alternative technologies or approaches available?
- Could a different resource deliver equivalent customer value?
- **Example**: Satellites substituting for broadcasting licenses

## Core Competency Identification

For capabilities (bundles of skills/technologies), apply three tests:

### Test 1: Market Access
Does the competence enable entry into multiple markets?
- Can it be applied across product lines?
- Does it support diversification opportunities?

### Test 2: Customer Benefit Contribution
Does it significantly enhance end-product value perception?
- Would customers pay more or choose you because of this?
- Is it visible in final benefits received?

### Test 3: Collective Learning & Imitation Barrier
Is it rooted in organizational learning and coordination?
- More than sum of individual skills?
- Difficult to replicate because it depends on how pieces fit together?

**Key distinction**: Core competencies are roots (enabling many products); products are fruits. Competencies often remain invisible like a tree's root system.

## Execution Workflow

```
Step 1: Identify candidate resource/capability
Step 2: Apply VRIS (for tangible resources) OR Core Competency Tests (for capabilities)
Step 3: Document which criteria pass/fail and why
Step 4: Classify outcome:
  - Strategic Resource: Passes all VRIS
  - Core Competency: Passes all three tests
  - Temporary Advantage: Passes some, vulnerable
  - Competitive Parity: Valuable but not rare
  - Disadvantage: Fails value test
```

## Output Format

| Element | Assessment |
|---------|-----------|
| Resource/Capability | [Name] |
| Classification | Strategic Resource / Core Competency / Neither |
| Criteria Passed | List with evidence |
| Criteria Failed | List with vulnerability analysis |
| Strategic Implication | Build/Protect/Exploit/Discontinue |
